## How to Redeem Codes Without Wasting an Hour

Here's the honest caveat up front: nobody in the source thread documented the exact menu path. Players listed strings and confirmed results, but skipped the "here's where I typed it" step. What follows is the general pattern for this kind of unlock, plus the troubleshooting that actually explains most failures.

| Step | Action | Why it matters |
|---|---|---|
| 1 | Open the pause or options menu and look for a text-entry field | Most indie unlock codes live one layer deep, not on the main menu |
| 2 | Check the main menu too if the pause menu has nothing | Some builds only expose the field before a run starts |
| 3 | Type the string with underscores exactly as written | Underscores are part of the code, not separators |
| 4 | Avoid trailing spaces | Mobile and controller keyboards add them silently |
| 5 | Confirm and return to the skin or customization screen | Unlocks usually apply on the next screen load, not instantly |
| 6 | Restart the game if nothing changes | Cosmetic flags sometimes only refresh on boot |

A few practical notes from player experience:

- **Capitalization appears not to matter.** The same gold code was posted as `Gold_Red_Phone`, `gold_red_phone`, and `GOLD_RED_PHONE` by three different people, all of whom said it worked. If your attempt fails, case is probably not the culprit — spelling is.
- **The underscores are the most common failure point.** Typing `gold red phone` or `goldredphone` will not work.
- **Don't stack codes in one session and assume all of them landed.** Redeem one, back out, check the skin list, then do the next.
- **A failed code gives no useful error.** Players report silence rather than a rejection message, which is exactly why the gold code took so long to pin down.
