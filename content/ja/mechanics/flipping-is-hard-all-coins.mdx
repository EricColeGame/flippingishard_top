## 黄金の馬コインは全部で何枚ある？

[Flipping is HardのSteamコミュニティディスカッション](https://steamcommunity.com/app/3826670/discussions/)で共有されているプレイヤー体験によると、コレクティブルは**14枚の黄金の馬コイン**で構成されています。この数字がすべての基準です。Flipping is Hard 全コインを目指すなら目標は14枚で、作成するチェックリストも14まで数えたら終わりにしましょう。

実際に追跡しているものを分けて考えると役立ちます。プレイヤーはこれらを混同し、何が足りないのかわからなくなりがちだからです。

| 追跡するもの | コミュニティ報告の詳細 | 重要な理由 |
|---|---|---|
| 黄金の馬コイン | Steamディスカッションのスレッドによると全14枚 | 主要なコレクティブルであり、実績の目標 |
| 実績 | フルセットを完成させると解除 | 本当にコンプリートした証拠 |
| Coin%カテゴリ | コイン収集を中心に組まれたスピードランルート | ルート化されたクリアがどれだけ速いかを示す |
| 公開ベンチマーク | コミュニティが投稿した8分29秒前後のデモラン | 現実的な参考値であり、必須条件ではない |
| セーブ状態 | 進行状況はセーブと終了の方法に左右される | 一部の奇妙な解除報告を説明できる |

実践的な要点は、セットを14個の番号付きスロットからなる有限のリストとして扱うことです。特定の番号を指して「これだ」と言えるようになれば、推測は終わり、解決が始まります。

## Flipping is Hard 全コインへのステップバイステップルート

ランダムに歩き回ることが、コインを取り逃す最大の理由です。ルートはスピードラン向けに最適化されている必要はありません。再現可能で、確認可能であれば十分です。以下のフェーズは初回クリアにも、失敗後のクリーンアップ周回にも使えます。

| フェーズ | やること | うまくいく理由 |
|---|---|---|
| 1. まず下見 | 何も取らずに新しいエリアを移動し、足場や隙間を確認する | 実際に回収する前に空間の形を把握できる |
| 2. チェックリストを作る | リストに1〜14の番号を振り、拾うたびに印を付ける | 記憶は不確かだが、リストは違う |
| 3. 一方向に進む | 左から右（または上から下）に進み、引き返さない | 「これもう取ったっけ？」のループを防ぐ |
| 4. 退屈な場所を確認する | 角、行き止まり、カメラから少し外れた場所 | 取り逃しは視覚的に地味な場所で起こりやすい |
| 5. 終了前に確認する | セーブして終了する前に枚数を確認する | セッション間で進行状況を見失うのを防ぐ |
| 6. クリーンアップ周回をする | 足りない番号だけを意識して再プレイする | 全体の再プレイを短い狙い撃ちの旅に変える |

セットを早く終えるプレイヤーと行き詰まるプレイヤーを分ける習慣が二つあります。一つは書き留めることです。スマホのメモに14個のチェックボックスを作るだけでも、複数セッションにまたがって記憶を頼りにするより確実です。もう一つは、コインを見つけた瞬間に取りたくなる衝動を抑えることです。見つけやすいコインは戻ってくるのも簡単なので、まずエリアの下見を終え、その後で意図的に回収しましょう。

ゲームの世界の一部が進行度で制限されている場合、フェーズ1の価値はさらに高まります。見えるけど届かないコインに気づいたら、その番号をメモして先へ進みましょう。まだ開いていないアプローチに10分費やす必要はありません。

## トラブルシューティング：コインが表示されないとき

「13枚で止まっている」という話のほとんどは、いくつかのパターンに当てはまります。何かを再起動する前に、この表を使ってください。

| 症状 | 考えられる原因 | 試すこと |
|---|---|---|
| 14枚中13枚で止まっている | 明確な視覚的合図なしに取得が登録された | 最初のエリアを歩き直す。取り逃しは序盤に取ったつもりのコインであることが多い |
| コインは見えるが届かない | ルートまたは進行度のゲートがまだ開いていない | 場所をメモし、先に進み、後で戻る |
| 実績が解除されない | セットが実際には未完成、またはセッションが変な形で終了した | 枚数を確認し、再読み込みし、実績リストを確認する |
| ルートが投稿されたランより遅く感じる | 妥当な順番で回収していない | Coin%のランを見て、小技ではなく順序をコピーする |
| どれを持っているか思い出せない | 書面のトラッカーがない | 番号付きリストを作り、エリアごとに記憶から再構築する |

コミュニティ報告には、ゲーム内のセーブして終了オプションではなく、ウィンドウの閉じるボタンでゲームを閉じた後に実績が解除された、という事例が少なくとも一件あります。これは一つの逸話であり、戦略ではありません。ただし、実績がすぐに表示されない場合は、セーブが壊れたと決めつける前に、一度きれいに再起動してみる価値があるという良い注意喚起になります。

## Coin%スピードラン vs. カジュアル収集

セットを把握したら、次に気になるのは、カジュアルに狙うかタイマー付きで狙うかです。どちらも正当な遊び方で、最適化しているものが違うだけです。コミュニティが投稿したデモのCoin%ランは8分29秒前後で、ルート化されたクリアがどれくらいタイトになり得るかの目安になります。ただし、そのタイムは、まだあなたにはない筋肉記憶を前提としています。

| 要素 | カジュアル収集 | Coin%スピードラン |
|---|---|---|
| 目標 | セットを一度完成させる | できるだけ速くセットを完成させる |
| ルート | ゆるく、エリアごと | 固定順序、記憶済み |
| リスク許容度 | 低い — すべて再確認できる | 高い — コインを一つ逃すとランが終わる |
| セッションの長さ | 柔軟 | 短く、繰り返し可能 |
| 学べること | マップとコインの配置 | 移動効率とルート規律 |
| 最適な開始地点 | 最初のプレイスルー | セットを一度クリアした後 |

賢い進め方は段階的です。まずカジュアルにセットをクリアし、14枚すべての場所を覚え、それから時間を計り始めましょう。いきなりタイム付きルートに挑むと、二つのことを同時に学ぶことになり、コインを一つ逃すだけでその試行が台無しになります。

## よくある質問

**Flipping is Hard 全コインでは何枚のコインを集める必要がありますか？**
Steamコミュニティディスカッションのプレイヤー報告によると、黄金の馬コイン14枚です。枚数が足りない場合、足りない一枚はほぼ必ず、急いで通り過ぎた序盤のエリアにあります。

**ゲーム内にコイン用のトラッカーはありますか？**
コミュニティのスレッドでは、確認できる情報は出ていません。確実な方法は、紙かスマホに番号付きリストを作り、エリアごとにチェックしていくことです。

**最後のコインを拾った瞬間に実績は解除されますか？**
通常ははい。ただしコミュニティ報告には、ゲームから特殊な方法で終了した後に初めて表示された事例が少なくとも一件あります。表示されない場合は、枚数を確認し、きれいに再起動してからもう一度確認してください。

**コインを永久に取り逃すことはありますか？**
これまでのコミュニティ報告には、その証拠はありません。取り逃した疑いがある場合は、セーブ全体をやり直すのではなく、そのエリアを再プレイしましょう。番号付きチェックリストを使ってクリーンアップ周回をする意味はまさにそこにあります。
