## ゲームプレイ概要：ローンチ版に含まれるもの

設定はわざと荒唐無稽だ。Flippyは脚のないスマートフォンで、小さなジェフが絶妙な位置に置かれたバナナの皮で滑り、Flippyは雨水溝に放り込まれてしまった。キャンペーン全体は、10の異なるエリアを越えてジェフのもとへ登り戻る旅である。

| 機能 | 実際の意味 |
| --- | --- |
| 移動 | 回転のみ、加えて振動ジャンプ |
| 構造 | 10エリア、1つの垂直目標 |
| 協力プレイ | オンライン、最大16人 |
| サポートツール | フレンドを助けるビームと電子レンジ |
| ボイス | 近接チャット |
| アクセシビリティ | チェックポイント付きの任意のChill Mode |
| RTA | クイックリスタートと内蔵スプリット |
| サイドコンテンツ | 16種類のNPCチャレンジ、スマホのカスタマイズ、解除できるクラシック携帯ゲーム |

操作体系が笑いの種であり、同時に挑戦のすべてでもある。脚がないため歩くことはできず、体を回転させ、短い振動ホップで高さを稼ぐ。小さなミスで転げ落ちてしまい、ストアの説明文が「落下はバグではなく設計の一部」と警告しているのもそのためだ。

協力プレイは、本作が一般的な高難度プラットフォーマーと一線を画す部分だ。16人が同じサーバーを共有し、ビームや電子レンジを置いて互いのルートを作り、近接チャットで会話する。つまりレベル内で最も近くにいる人が、悲鳴を上げているのを聞ける相手ということになる。ソロプレイヤー向けには、Chill Modeがチェックポイントを有効にし、厳しい登りをこなせるストーリーランに変えてくれる。

RTA対応は後付けではなく最初から組み込まれている。即時リスタートと統合スプリットにより、ルート練習に外部タイマーは不要だ。16種類のNPCサイドチャレンジは精密な動きを実行できるプレイヤーに報酬を与え、スマホのカスタマイズシステム（ケース、チャーム、ステッカー）と解除できるクラシック携帯ゲームが、メインの登り以外に収集要素の層を加えている。
