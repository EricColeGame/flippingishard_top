## Steam版「Flipping is Hard」とは？

Flipping is Hardは、インディー開発者Elegant Horse Studiosによる物理演算ベースの登攀プラットフォーマーで、SteamでPC向けダウンロードとして販売されている。プレイヤーは、脚も腕もなく、重力に対して一切の我慢もしないスマートフォン「Flippy」を操作する。設定はわざと馬鹿げている。小さなJeffが絶妙な位置に置かれたバナナの皮で滑り、Flippyを誤って雨水溝へ吹き飛ばしてしまい、今では二人は離れ離れだ。目的はJeffの元へ登り返し、このコンビにふさわしいハッピーエンドを迎えることだ。

特徴は操作体系にある。歩くことも走ることもできず、入力は回転と振動ジャンプだけだ。簡単に聞こえるが、あらゆる表面がパズルであり、ミスの代償は失った高度で測られることに気づけば話は別だ。ストアページにもはっきり書かれている。これは忍耐力を試す難しいゲームであり、落下もチャレンジの一部なのだ。

## ソロと協力プレイ：まったく異なる2つの登攀

Flipping is Hardは2つの異なる遊び方をサポートしており、それぞれ別のゲームのように感じられる。ソロは純粋主義者のルートだ。移動を学び、落下を繰り返し、自分のペースで物語を体験する。協力プレイは同じ登攀をグループプロジェクトに変え、最大16人の友達が一つの非常に高く、非常に滑りやすい問題を共有する。

協力プレイ層は単に「同じ足場にいるプレイヤーが増える」だけではない。チームには共有ツール「Beams」と「Microwaves」が与えられ、難しい区間を互いに助け合って越えられる。落下地点の底で誰かを見捨てる必要はない。近接チャットも搭載されており、叫び声も設計の一部だ。コミュニティの報告では、協力プレイはチームワークとコメディが半々だと語られており、「友情」を試すものとして堂々と挙げている本作らしい。

## 移動、レベル、共有ツール

Flipping is Hardのすべては一つの考えから流れている。勢いは与えられるものではなく、勝ち取るものだ。Flippyは回転とホップしかできないため、隙間を越えるには正しい角度を作り、ジャンプのタイミングを合わせ、急いだ入力は物理演算が許さないと受け入れる必要がある。頂上までには10のエリアがあり、それぞれが同じ小さな技セットに新しい表面と危険を重ねていく。

本作は、痛みへの耐性が異なるプレイヤーにもわざわざ配慮している。Chill Modeは、苦痛を少なく物語を楽しみたいプレイヤー向けにチェックポイントを追加する。一方、スピードラン向けにはクイックリスタートと内蔵スプリットが用意され、無駄にしたフレームまで計測したいプレイヤーに対応する。

| メカニクス | 仕組み | 重要な理由 |
| --- | --- | --- |
| 回転のみの移動 | 回転が唯一の操作 | すべての角度が判断になる |
| 振動ジャンプ | 跳躍ではなく短いホップ | 距離より精度が勝つ |
| 過酷な登攀 | 10エリア、頂上の目標は一つ | 小さなミスが大きな落下を生む |
| Chill Mode | 任意のチェックポイント | 基本ゲームを変えずにアクセシビリティを向上 |
| スピードラン用ツール | クイックリスタートと内蔵スプリット | 繰り返し挑戦の摩擦を軽減 |
| NPCチャレンジ | サイドクエストを持つ16人のキャラクター | 移動の専門家向けの追加テスト |
| コスメティック | スマホケース、チャーム、ステッカー | 苦しみながらFlippyをカスタマイズ |
| 作中のスマホゲーム | アンロックできるクラシックなモバイルゲーム | スマホの中で本物の気晴らしになる |

最後の項目には触れておく価値がある。スマートフォンについてのゲームの中で、遊べるレトロ風モバイルゲームを探してアンロックするというのは、きちんと決まるジョークであり、コンプリート勢にメインの登攀以外を探索する理由を与えてくれる。

- **跳ぶ前に狙う。** 回転が発射角度を決めるので、まず傾きを合わせ、その後にジャンプする。パニックジャンプがほとんどの落下の原因だ。
- **一度に1エリアずつ学ぶ。** 10ゾーンは多くないが、それぞれがひとひねり加えてくる。登攀を急がないこと。

- **適切な友達を連れてくる。** 近接チャットは仕様であり、バグではない。落下を笑える人を選ぼう。
- **NPCと話す。** 16人にはチャレンジがあり、そのサイドクエストは移動技術を磨く最短の道だ。

## Flipping is Hard Steam よくある質問

**Flipping is HardはSteamで買う価値がある？**
難しい物理プラットフォーマーのファンなら、はい。Flipping is HardのSteam版は定価$14.99で、控えめなハードウェアで動作し、ソロの物語登攀と16人協力プレイの両方を提供する。ミスを罰するゲームが苦手なら、Chill Modeを試すか、より深いセールを待とう。

**Flipping is Hardは友達と遊べる？**
はい。オンライン協力プレイは最大16人に対応し、BeamsやMicrowavesなどの共有ツール、内蔵の近接チャットがある。集団での失敗を笑って楽しむグループ向けに設計されている。

**Flipping is Hardにイージーモードはある？**
Chill Modeがある。より寛容な登攀のためにチェックポイントを有効にする任意設定だ。Chill Modeをオフにすれば基本難易度は変わらない。

**Flipping is HardはSteam Deckに対応している？**
未確認だ。ストアページではSteam Deck対応状況が「Unknown」とされているので、携帯機でのプレイを計画する前に最近のプレイヤー報告を確認しよう。

**ゲームに必要な容量は？**
2ギガバイト。最低要件と推奨要件の両方に、2 GBの空きストレージと記載されている。
